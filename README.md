# Site Ellen Maia - Professora de Inglês

Versão estável do site profissional para a professora de inglês Ellen Maia.

## ✅ Status atual

Projeto funcional e responsivo, com as seguintes características:

- Menu mobile com overlay funcional (abre/fecha corretamente)
- Menu desktop horizontal com links suaves
- ScrollReveal para animações de entrada
- Scroll ativo destacando a seção atual
- Botão "voltar ao topo"
- Estrutura pronta para integração com EmailJS (basta configurar as chaves)

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3 (com media queries e variáveis)
- JavaScript puro (ES6)
- ScrollReveal (via CDN)
- EmailJS (via CDN, aguardando configuração)
